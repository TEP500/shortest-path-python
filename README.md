# Shortest Path and Route Optimization

Computational Mathematics Laboratory project, implemented in Python.

## Contents
- `shortest_path_lab.py` – all algorithms: Dijkstra, Bellman-Ford, Floyd-Warshall, BFS, A*, nearest neighbour, 2-opt, brute-force TSP
- `app.py` – optional Streamlit web interface
- `figures/` – output plots from the script

## Run
```
pip install -r requirements.txt
python shortest_path_lab.py     # prints results, saves figures
streamlit run app.py            # interactive web app
```
